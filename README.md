# TDD-BDD-Final-Project

## Project Name
TDD-BDD Final Project

## Project Description
This project demonstrates Test Driven Development (TDD) and Behavior Driven Development (BDD) using Python. It includes automated testing, test cases, and BDD scenarios.

## Technologies Used
- Python
- GitHub
- Nose
- Coverage
- Flake8
- Behave

## Usage

This repository is used as a template to create your own repository in your GitHub account.

## Setup

After entering the lab environment, run the setup script in the `./bin` folder to install the prerequisite software.

```bash
bash bin/setup.sh
```

Then exit the shell and start a new one.

```bash
exit
```

## Tasks

The project uses Test Driven Development (TDD) and Behavior Driven Development (BDD) techniques.

The following files are used:

```text
tests/test_models.py
tests/test_routes.py
service/routes.py
features/products.feature
features/steps/load_steps.py
```
